In the first two passes, textedit-save hung TextEdit. Claude set the text with `setValue` and then
pressed Cmd+Shift+S, expecting Save As. In TextEdit that shortcut is Duplicate, and TextEdit's main
thread then waited forever on the document's save lock (seen in a `sample` of the process). Every
read timed out, and the relay reported a stuck helper, though the helper itself still answered
`--doctor`. In the first pass the benchmark's TextEdit setup then crashed on the hung app; it now
times out and goes on. In the second pass the hung TextEdit also failed textedit-edit and
textedit-drag. Quitting TextEdit cleared it both times.

No earlier pass that day pressed Cmd+Shift+S, so this may be chance in two runs. The skill now says
Cmd+Shift+S is Duplicate in apps with autosave and points Claude at Cmd+S or File > Save As. After
that, all six TextEdit runs passed. Both hung runs left an "Untitled 6.txt" in the iCloud TextEdit
folder, which went to the Trash.

calculator-click, calculator-menu and chess-drag passed 1/1 each.
