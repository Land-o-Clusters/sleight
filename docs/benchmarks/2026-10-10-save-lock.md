# TextEdit save-lock experiment

Worktree `~/Projects/sleight-wt/savelock-engine`, branch `codex/savelock-engine`, based on `pane/auto-mode`.
Plugin behavior is unchanged. No live run on this branch.

## Delivery

After an Accessibility text write, TextEdit's next Cmd+S deadlocked on the document's save lock in
10 of 13 trials on 2026-10-08 when the file was opened through the Open panel, and in 0 of 3 opened
with `open -g` ([known problems](../known-problems.md)). Those hangs used the engine's
`pressKey("super+s")`.

On 2026-10-11, Cmd+S posted to a background TextEdit PID never saved (2/2 runs). S down with the
Command flag failed, and so did Command down and up around S. A posted `x` did arrive.
Counting the 2026-10-08 hangs needs the engine's Cmd+S on an Open-panel file.

## Runner

`bench/textedit-save-lock.mjs` drives TextEdit through the relay (`probeClient`, `relay: true`,
`relayOptions: { changeReview: false, spaceProbe }`). It opens a unique
`/private/tmp/sleight-save-lock-*/trial.txt` with Cmd+O, Cmd+Shift+G and the path, writes the marker
through Accessibility, then `pressKey("super+s")`. The Open panel shows the home folder: the runner
never captures it, and published JSON omits those frames.

The gate is 5 control runs. Interleaved Shift-after-write variants run only if 3 of those hang.
Cleanup looks up TextEdit's PID at close time and closes only the owned document.

`--delivery-check` types through the engine, with no Accessibility write, and requires
`pressKey("super+s")` to save within 2 s.

## Checks

The unit tests failed against the PID-posted Cmd+S runner (7/11: open-panel keys, engine save,
typed delivery-check, dry-run plan, fixture Cmd+S posting). They passed 11/11 after the switch.
Dry-run:

```bash
node bench/textedit-save-lock.mjs --dry-run
node bench/textedit-save-lock.mjs --dry-run --delivery-check
```

Both exit 0 and leave `/tmp/sleight-live.lock` untouched.

## Live check

TextEdit already running in the background. From this worktree, with the live lock free:

```bash
node bench/textedit-save-lock.mjs --delivery-check
node bench/textedit-save-lock.mjs
```

`--delivery-check` must save the typed file within 2 s. The hang run must open through the Open
panel, write through Accessibility, save with `pressKey("super+s")`, print counted hangs, skip
variants when the gate hangs fewer than 3 of 5, and leave Open panel frames out of the published
JSON. Do not quit ChatGPT.
